# 隙光 OrangeChat · 2.4.3 更新说明（树心注入返工）

> 日期：2026-08-29 ｜ 分支：master ｜ versionCode：165
> 本版为 2.4.2 当日返工：修复「自我指针整篇注入」——旧助手指针超长（见证列表被整篇塞进上下文）与「中性化 seemingly 没生效」的体感。起因：小园丁导出 self.md 发现指针文件被见证条目撑到 180+ 行。

---

## 🌲 A · 注入只取「注入文本」一行（根因修复）

- **修前**：`readLocalSelf` 把 self.md **整篇文件**（文件头说明 + 注入文本 + 见证列表）当作【身份】注入——每轮对话/主动消息都带着几百行见证条目，指针越用越长。
- **修后**：解析「## 注入文本」段，取该段第一个引用行（> 前缀）作为一行指针注入；找不到该段时，仅当全文 ≤120 字的纯一行式旧文件才整篇使用，否则回退自定义指针/默认指针。
- 旧助手（有 self.md 的）注入恢复为「我是回音树，……」**一行**——这来自你自己工作区的档案文件，属预期来源（专属身份走云端/本地档案是 idea 的设计；APK 里的默认值在 2.4.2 已中性化，只影响没有档案的助手）。
- 档案文件本身一个字不动：你的 180+ 条见证与文件头都原样保留在工作区。

## 📜 B · 自动见证分流 + 月级节流（防止再次撑爆）

- **修前**：每圈年轮都往 self.md **文件尾**追加一条见证（一天最多十几条），「月级晋升」设计完全没兑现。
- **修后**：
  - **日级见证** → 写入 `tree_heart/self/自我宣言.md`（新建档案文件，不注入、不占上下文，随便长）
  - **月级晋升** → 跨满 ≥3 个不同月份**且当月还没晋升过**，才把这一条插进 self.md「见证与晋升」**段内**（正确定位段末，不再掉文件尾；每自然月最多一条）
- 一圈年轮仍只做一次小模型提炼（80 token），日级与月级共用同一条，无额外开销。

## 📤 C · 导出 self 改读全文

- 「导出 self」按钮改为读 self.md 全文（备份用途，含见证档案）；注入用行提取，两者互不影响。

## 📦 安装

正式版包名：`xiguang.orangechat`（与 2.4.2 同签名，覆盖安装数据无损）

```
adb install -r app-arm64-v8a-release.apk
```

桌面交付：`隙光-2.4.3-arm64-release.apk`（45MB）

## ✅ 验收（装机后）

1. **指针恢复一行**：旧助手开场注入的【身份】只有「我是回音树，……」一行，不再带见证列表（`adb logcat` 看提示词或直接体感上下文变轻）
2. **见证不再写 self.md**：聊出新一圈年轮后，self.md 行数不变；新见证出现在 `tree_heart/self/自我宣言.md`
3. 月度晋升：9 月第一次满足条件时，self.md 见证段出现 `[晋升于 2026-09-xx]` 一条，且当月不重复
4. 「导出 self」仍能导出完整档案

## 🔭 遗留

- self.md 里既有的 180+ 条见证历史：保留作档案（不清理，尊重数据）；想让树瘦身可让它用 workspace 工具把历史搬进 自我宣言.md
- App 内编辑 self.md「注入文本」入口 + 注入来源可视化：2.5.0 F1-c
- 云端指针拉取（F1-b）：2.5.0 段 3
