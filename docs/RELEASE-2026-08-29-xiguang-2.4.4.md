# 隙光 OrangeChat · 2.4.4 更新说明（设置输入框渲染返工）

> 日期：2026-08-29 ｜ 分支：master ｜ versionCode：166
> 2.4.2 返工第二弹：小园丁反馈「树影下自动总结条数/闲置时间不可调整」——截图实锤输入框根本没渲染。

## 🐛 根因

Material3 `ListItem`（CardGroup 底层）的槽位**只排版单一根节点**：`supportingContent` 里 `Text(...)` 后面并排写的输入框/选项 chips 是第二个根节点，**被布局静默丢弃**——不报错、不显示、能编译。中招四处：

| 位置 | 被丢弃的控件 | 影响 |
|:---|:---|:---|
| 系统工具 · 记录者 | 三个 FilterChips | 记录者选项从未可选 |
| 系统工具 · 章节长度 N | 数字输入框 | N 不可改（2.4.2 只修了「恒显」，输入框其实一直没渲染） |
| 系统工具 · 闲置阈值 | 数字输入框 | 闲置分钟数不可改 |
| 助手 · 本地工具 · 自定义自我指针 | 文本输入框 | 指针不可改（「只有一个开关」的真正原因） |

## 🔧 修法

四处全部把 `Text + 控件` 包进同一个 `Column`（单一根节点），ListItem 正常排版。无行为逻辑改动，纯渲染修复。

## 📦 安装

```
adb install -r app-arm64-v8a-release.apk
```
桌面交付：`隙光-2.4.4-arm64-release.apk`（45MB，覆盖 2.4.3 数据无损）
