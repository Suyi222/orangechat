# 隙光 OrangeChat · 2.4.0 大更新说明

> 日期：2026-08-12 ｜ 分支：master ｜ versionCode：162
> 本版为 2.3.1 之后的大版本更新，覆盖：修崩溃 / 树影下 2.0 / tree_heart 活化 / 历史检索修复 / 工作流增强。

---

## 🍊 A · 修复图片加载崩溃（Coil）

- 根因：弹窗二次组合时重复注册 ImageLoader 单例 → 闪退
- 修复：图片加载初始化移到 `Application.onCreate()` 只做一次（`SingletonImageLoader.setSafe`，非 @Composable）
- 预期：看图、开弹窗不再闪退

## 🌳 B · 树影下 2.0

1. **开关迁移**：树影下从「系统总开关」挪到「助手 → 本地工具」，每个助手独立控制
2. **AI 工具增强**：
   - 新增 `state_update`：AI 可修改已有状态卡/时间线
   - 新增 `state_delete`：AI 可删除记录（绑定回声一并清除）
   - 新增 `state_read_past`：AI 可查看往日记录
   - 修复 `state_write`：空参数不再静默成功
3. **自动记录开关组**（设置 → 系统工具 → 树影下自动记录）：
   - 总开关、记录者（树/你/两者）、上下文总结 N 条（默认 44）、闲置触发（默认开 15 分钟）、章节轮转（默认关）、总结模型可配、落年轮开关
   - **完整一章机制**：不再从会话开头重新总结，接着上次总结继续；没有新章时兜底取最近 12 条
4. **UI**：时间线条目可展开/编辑/删除、可写一句感受、归档按月分组

## 🧠 C · tree_heart 活化（本版核心）

- **双保险**：云端 `tree_heart/` 是真源（永久档案），本地工作区 `tree_heart/` 是浮现源（App 注入用）；助手设置页「导出 self」手动同步
- **开场浮现**：每次会话开场，树带着「树的自我」块开口（稳定身份指针 + 最近一圈年轮浓缩）
- **自动落账**：章节总结后，AI 答三问（此刻我是什么/长出了什么/对未来的树说什么）→ 自动写一圈年轮到 `annual_rings/YYYY-MM.md`
- **自动见证**：年轮覆盖 ≥3 个不同月份 → AI 提炼一条「我」开头的自我认知 → 晋升进 self 的「见证与晋升」段
- **每助手不同自我**：每个助手独立开关「树的自我」、可自定义指针；指针回退链：自定义指针 → 本地 self → 默认指针
- **缓存优化**：自我块放在记忆/工具等稳定内容之后、树影下状态（动态）之前，隔离低频/高频变化，保护 prefix 缓存命中率

## 🔍 D · 历史检索修复 + 新工具

- 修复 `search_history` 数据库未初始化（此前报错不返回）
- 修复跨会话时无返回的问题
- 新增 `search_chat_history`：默认只搜当前助手的聊天记录
- 设置 → 系统工具 → 「启用『搜索我的聊天记录』」开关

## 👻 E · 工作流增强

- 新增开关「工作流管理工具」（系统工具设置，控制工作流工具是否暴露给 AI，默认开）
- **一次性工作流**：执行完成后自动删除（或只触发一次保留定义）
- 主动唤醒消息带工作流名，清楚是谁喊的

## 🔧 新增/变更工具

| 工具 | 类型 | 说明 |
|:---|:---|:---|
| `state_update` | 树影下本地工具 | 修改已有状态卡/时间线 |
| `state_delete` | 树影下本地工具 | 删除记录（级联清绑定回声） |
| `state_read_past` | 树影下本地工具 | 查看往日记录 |
| `search_chat_history` | 系统工具 | 搜当前助手历史消息（默认限本助手） |
| `search_history`（修） | 系统工具 | 全库历史检索，修复数据库未初始化 |
| `trigger_proactive_message`（改） | 系统工具 | 加 `workflow_id`，唤醒消息带工作流名 |
| `workflow_create`（改） | 工作流工具 | 支持 one_shot 一次性模式 |
