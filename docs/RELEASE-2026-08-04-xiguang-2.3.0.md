# 隙光 OrangeChat · 2.3.0 大更新说明

> 日期：2026-08-04 ｜ 分支：feature/workflow-widget-v2
> 本版为「橘瓣 OrangeChat」正式二改为「**隙光**」后的第一次大版本更新。

---

## ✨ 品牌：橘瓣 → 隙光

- 应用名称、图标、加载动画等全部切换为「隙光」视觉（暗夜花园风格）
- 源码注释同步更新为隙光项目标识

## 🌲 树影下 · 状态系统

状态卡（State Card）机制正式上线：

- **状态卡**：AI 每次生成回复前自动读取当前状态卡，像「状态指纹」一样感知用户当前处境
- **备注模块**：AI 可自行决定是否在状态卡上写备注（不写也正常），写了会打包进上下文
  - 备注 = 长期便签，随状态卡一起归档
- **往日页**：已归档的状态卡 + 备注按时间线保存，可回看
- 树影下入口：抽屉（侧边栏）→ 树影下（今天 / 往日双 Tab）
- 新增数据表 `tree_shadow`（Room v30，AutoMigration 自动升级，数据无损）

## 🕐 随机时间触发器（random_time_between）

工作流新增随机时间段触发器，适合「查岗 / 主动关心」场景：

- 在 `start ~ end` 时间段内随机触发（支持跨午夜，如 22:00~08:00）
- `min_interval_minutes`：两次触发最小间隔（默认 120）
- `max_triggers_per_day`：每日触发上限（默认 3）
- 每次触发后自动重排下一次随机点；达每日上限后跳到次日窗口，不再空跑

## 🛡️ 后台工具调用总开关

替代旧「主动唤醒白名单」，一键解决「白名单覆盖不全、高权限工具被拦」的痛点：

- 设置 → 主动消息 → **允许 AI 在后台调用工具**
- 开启后**真·全开**：主动消息 / 激进模式中，AI 可自由调用全部工具（含获取位置、切换屏幕、读取通知等需要审批的工具），直接执行不再拦截
- 默认关闭（安全态）；开启入口带高权限警示说明
- 旧白名单（候选勾选 + 自定义工具名）已移除

## 🔔 工作流主动唤醒卡

修复「AI 被工作流唤醒时只知道时间、不知道被谁唤醒要干嘛」的问题：

- 工作流 `trigger_proactive_message` 触发时，AI 上下文注入完整**唤醒卡**：
  1. **醒因**：明确告知「你是被工作流主动唤醒的，不是定时提醒，也不是用户主动找你」
  2. **要做什么**：工作流预留的提示消息原样送达
  3. **当前时间**：唤醒卡自带星期 + 时刻，时间感知不丢失
- **抑制 time_reminder 抢戏**：工作流唤醒时不再注入 `<time_reminder>`，AI 第一反应归因于工作流唤醒而非时间提醒
- 唤醒卡提到用户消息层（AI 第一眼看到），系统提示层只留规则声明兜底

## 📚 其他

- 修复多处编译问题与状态注入顺序（树影下状态注入置于工具之后，提高缓存命中率）
