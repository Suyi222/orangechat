# 隙光 OrangeChat · 2.4.2 更新说明（稳定性 hotfix + 埋点 + 隐私止血）

> 日期：2026-08-29 ｜ 分支：master ｜ versionCode：164
> 本版为 2.4.1 之后的过渡 hotfix：10 件小改（全部独立 commit，可单项回滚），主体是 8-25 崩溃族系修复、主动消息全链路埋点、晨信双信加固第一步与自我指针隐私止血。聊天/插件行为与 2.4.1 完全兼容，QuickJS 沙箱与工具注册零改动。

---

## 🩹 A · 稳定性修复

1. **悬浮球软渲染崩溃**（8-25 实测）：悬浮球头像 ImageRequest 加 `allowHardware(false) + crossfade(false)`——vivo 悬浮窗走软件渲染时画硬件位图必崩的问题根治（工作流 `bring_chat_to_front` 拉前台后崩溃的主因）。
2. **「章节长度 N」输入框无条件渲染**：2.4.0 起它被默认关闭的「章节轮转」开关条件隐藏，想改 N（默认 44）在设置页找不到——现在恒显，开关只控制章节轮转是否启用。
3. **自动总结失败可见化**：`summarizeSegment` 五处静默 return 全部加 `TreeShadowSummary` 日志（模型缺失/无 provider/会话缺失/空窗口/总结为空），失败原因 `adb logcat -s TreeShadowSummary` 直接可见。
4. **设置读盘失败不再无声降级**：DataStore 读盘 IOException 时记 `Log.e` + 写标记，下次启动 SafeMode 页横幅 / 主界面一次性 Toast 提示「设置读取失败，部分配置可能已重置」——8-25「崩溃后设置被重置」的防护层。
5. **SafeMode 页加「进入主界面」按钮**：崩溃后不再只能返回键退出重进。

## 🔍 B · 主动消息全链路埋点（零行为变化）

- TAG=`ProactiveTrace`：入口（来源/force）→ 总开关判定 → min_interval 跳过 → 助手与模型解析 → 并发抢占 → provider 解析 → 生成开始（模型/历史条数/工具数）→ 生成结束（回复长度/PASS）→ 取消/错误，共 10 个断点；工作流工具 `trigger_proactive_message` 入口也有一行。
- 用法：`adb logcat -s ProactiveTrace`。**2.4.2 装机后正常使用 1~2 天**，若主动消息再「不触发」，链路断点直接可见，届时凭日志定位修复（2.5.0-B）。

## 📮 C · 晨信双信加固（第一步）

- 随机触发器每日计数 `apply()` → `commit()` 同步落盘：崩溃窗口内计数不再丢失，「每日上限 1」失效的机制堵住（8-26/8-27 双信案，详见诊断书 §十）。
- 重启判重 + RUNNING 先行落盘在 2.5.0 段 3 收尾；插件侧「先查再写」缓解层继续观察。

## 🔒 D · 自我指针隐私止血（F1-a）

- 默认自我指针改为中性文案「我是你的 AI 伙伴……」——「回音树 × 小园丁」专属句**退出代码**（idea 2026-08-08 隐私危机，任何人装这个 App 都是普通 AI 伙伴）。
- 回音提示、总结/年轮 prompt、指针示例等其余专属文案一并中性化；源码级零残留（`grep 回音树|小园丁` 仅剩注释）。
- 专属身份改由两条路承载：助手 → 本地工具 → 自定义指针（现在就可用）；云端 `tree_heart/self/树的自我指针.md` 拉取注入（2.5.0 F1-b，通道与树心同步共建）。
